# Package index

## All functions

- [`AnnotationBust()`](http://sborstein.github.io/AnnotationBustR/reference/AnnotationBust.md)
  : Breaks up genbank sequences into their annotated components based on
  a set of search terms and writes each subsequence of interest to a
  FASTA for each accession number supplied.
- [`AnnotationBustR`](http://sborstein.github.io/AnnotationBustR/reference/AnnotationBustR.md)
  : An R package to extract sub-sequences from GenBank annotations under
  different synonyms
- [`FindLongestSeq()`](http://sborstein.github.io/AnnotationBustR/reference/FindLongestSeq.md)
  : Find the longest sequence for each species from a list of GenBank
  accession numbers.
- [`MergeSearchTerms()`](http://sborstein.github.io/AnnotationBustR/reference/MergeSearchTerms.md)
  : Merging of two tables containing search terms to expand search term
  database for the AnnotationBust function.
- [`cpDNAterms`](http://sborstein.github.io/AnnotationBustR/reference/cpDNAterms.md)
  : Chloroplast DNA (cpDNA) Search Terms
- [`mtDNAterms`](http://sborstein.github.io/AnnotationBustR/reference/mtDNAterms.md)
  : Mitochondrial DNA Search Terms for Animals
- [`mtDNAtermsPlants`](http://sborstein.github.io/AnnotationBustR/reference/mtDNAtermsPlants.md)
  : Mitochondrial DNA Search Terms for Plants
- [`rDNAterms`](http://sborstein.github.io/AnnotationBustR/reference/rDNAterms.md)
  : Ribosomal DNA (rDNA) Search Terms
