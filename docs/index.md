# AnnotationBustR[#annotationbustr](#annotationbustr)

AnnotationBustR: An R package to extract sub-sequences from GenBank annotations. For a detailed description of the package see Borstein SR, and O’Meara BC. 2018. AnnotationBustR: an R package to extract subsequences from GenBank annotations. PeerJ 6:e5179. 10.7717/peerj.5179.

For a detailed walkthrough on how to use AnnotationBustR, see the vignette: [https://github.com/sborstein/AnnotationBustR/blob/master/vignettes/AnnotationBustR-vignette.md](https://github.com/sborstein/AnnotationBustR/blob/master/vignettes/AnnotationBustR-vignette.md)
